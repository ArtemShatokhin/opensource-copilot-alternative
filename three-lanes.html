How to choose. If you want a desktop app that runs on your own machine, OpenWork. If you want agents that execute software tasks in isolation, OpenHands. If you want an org-scale system where agents, skills, memory and connectors live in a git repo you own — with review gates — Kortix/Suna is the lane-C option (source-available, not OSI-approved).
